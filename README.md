# NovelCreator

NCreator（Novel Creator）是一套面向中文短篇、中篇小说的结构化创作 Skill。它把故事定位、人物功能、主线与暗线、章节提纲、完整首稿/浓缩稿、丰满化、通篇修订和逐章预览组织成可追踪的创作流程。

## 核心能力

- 先建立项目台账、故事总观、人物功能表、主线暗线结构和章节提纲，暂不写正文
- 每个角色承担明确叙事功能，包括有辨识度的群演和背景人物
- 让暗线少露面但持续在关键节点产生回声，保留可讨论的推断空间
- 先完成从开端到结局闭合的完整首稿或浓缩稿，再按提纲丰满
- 通过人物博弈、选择代价和递进式心理压力增加故事张力
- 每次扩写或修改前后进行逻辑、文笔细节、人物连贯性三遍自查
- 修改以通篇理解为前提，默认按场景、段落群、章节或人物弧线调整，避免脱离上下文改单词单句
- 创作过程中和阶段结束后统计章节字数、阶段字数与全书累计字数，完稿时提供全稿与分章统计

## 三套运行时入口

| 运行时 | Skill 文件 | 安装方式 |
|---|---|---|
| Codex | [`codex/SKILL.md`](codex/SKILL.md) | 将 `codex` 目录复制到 `~/.codex/skills/ncreator` |
| Claude | [`claude/SKILL.md`](claude/SKILL.md) | 将 `claude` 目录复制到 `~/.claude/skills/ncreator` |
| DSH | [`dsh/SKILL.md`](dsh/SKILL.md) | 将 `dsh` 目录复制到 DSH 的 skills 目录 |

三份入口内容保持一致，名称均为 `ncreator`，显示名为 NCreator。下载仓库后，复制对应目录即可使用，不依赖额外包或网络服务。

每个运行时目录同时提供带版本号的规范文件（例如 `SKILL_v1.2.2.md`）和运行时默认识别的 `SKILL.md` 兼容副本；两者内容保持一致。版本号也写在文件内容中。

## 推荐调用

```text
使用 $ncreator，先为这个故事建立项目台账、故事总观、人物功能表、主线暗线结构和章节提纲，暂不写正文。
```

进入下一阶段时明确说明：

```text
骨架已确认。现在完成这部小说的完整首稿/浓缩稿，必须从开端写到结局，不进入丰满化。
```

```text
首稿已确认。现在严格按照既定提纲丰满，重点增加场景、人物博弈、心理压力、关系变化和因果后果，不改变核心结构。
```

## 创作阶段

```text
项目台账
  → 故事总观
  → 人物功能表与关系
  → 主线/暗线结构
  → 章节目录与提纲
  → 完整首稿/浓缩稿
  → 三遍自查
  → 按提纲丰满
  → 通篇理解后的成轮修订
  → 分章预览
  → 归档与整体复盘
```

默认先预览、不直接保存；预览不等于确认，写完不等于通过。每个项目建议同时维护信息控制表、重大选择与代价表，以及完稿整体复盘。

## 完稿交付

完成正文后生成清洁版 `XXX_交付稿.md`：章节标题统一为“第一章”至“第二十四章”。清理扩写、增补、补遗、审校、场景及中间版内容时，先将其中有价值的故事内容归入正文，再做时间线、因果、人物、暗线和视角一致性检查，确认无误后才删除过程性标题与内部标记；同时提供文字版人物结构概要和图片版人物关系图，推荐使用 `XXX_人物关系图.svg`。
